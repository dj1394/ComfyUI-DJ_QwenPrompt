# ComfyUI-DJ_QwenPrompt

> 版本 `260930-180257`

用本地跑的 Qwen Image 2.1 模型，把一句人话打磨成能直接喂给绘图模型的高质量提示词。支持文生图提示词、图生图提示词，也能反过来把一张图反推成提示词。

节点分类：**大江工具箱 / 提示词**
节点名称：**Qwen image 2.1 提示词优化 大江**

---

## 三种工作模式（自动判断，不用手动切换）

| 你接了什么 | 走哪种模式 | 干什么 |
|---|---|---|
| 只填了「用户提示词」，没接图 | 文生图模式 | 把你的想法扩写成完整绘画提示词 |
| 接了图 **且** 填了「用户提示词」 | 图生图模式 | 看着图，按你的要求改写提示词（改风格、换背景、调光线等） |
| 接了图 **但**「用户提示词」是空的 | 反推模式 | 把这张图反推成一段可复用的提示词 |

「是否反推」这个输出口会告诉你这次是不是走了反推模式，方便用开关节点分流。

---

## 输入参数

**必填**

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 用户提示词 | 多行文本 | 空 | 你的想法或修改要求。图生图模式下必填；留空且接了图就是反推模式 |
| 文生图模型 | 下拉 | 自动挑 PE-T2I | 文生图/反推模式用的主模型 |
| 图生图模型 | 下拉 | 自动挑 PE-I2I | 图生图模式用的主模型 |
| 视觉模型 | 下拉 | 自动挑 PE-I2I | mmproj 视觉投影模型，接了图就必须选 |
| 输出语言 | 下拉 | 自动 | `自动` / `中文` / `English` |
| 透明背景 | 开关 | 关 | 打开后提示词会带上透明背景（RGBA）相关描述 |
| 种子值 | 整数 | 0 | 0 ~ 4294967295 |
| 种子模式 | 下拉 | 固定 | `固定` 时每次跑结果一致；`随机` 时每次排队自动换新种子 |
| 卸载模型 | 下拉 | 自动 | `自动` / `保持加载` / `运行后自动卸载` / `运行前后自动卸载`。显存吃紧就用「运行前后自动卸载」 |

**可选**

- `图像_01` ~ `图像_10`：最多接 10 张图。接多少张都行，不接就纯文字工作。

---

## 输出

| 输出口 | 类型 | 内容 |
|---|---|---|
| prompt | STRING | 打磨好的提示词正文 |
| json | STRING | 结构化 JSON 版本，便于程序化接续处理 |
| 是否反推 | BOOLEAN | 本次是不是反推模式 |

同时会把实际使用的种子回填到界面上，方便复现。

---

## 界面上自动帮你做的事

- **图像接口自动增减**：一接上图，下面自动长出一个空接口；最多长到 10 个，空接口会自动收掉，不用手动加连线点。
- **提示词框能拖着改高矮**：拖过一次就记住，下次打开工作流还是这个高度。
- **随机种子自动换**：种子模式选「随机」时，每次点运行都会换成新种子，跑完还会把种子的使用状态记进工作流。

## 安装

1. 把整个 `ComfyUI-DJ_QwenPrompt` 文件夹放进 `ComfyUI/custom_nodes/` 下。
2. 确认已安装依赖（一般 ComfyUI 环境里已经有了）：
   - `llama-cpp-python` —— **必须是带 `Qwen35ChatHandler` 的版本**（0.3.48 与 0.4.0 实测可用）。这个包体量大、和显卡驱动绑定紧，**不建议直接 pip 覆盖**，先确认现有版本可用再动。
   - `numpy`、`Pillow`
3. 重启 ComfyUI，在「大江工具箱 / 提示词」分类下找 **Qwen image 2.1 提示词优化 大江**。
4. 改了前端 JS 后记得 `Ctrl+F5` 刷新浏览器缓存。

## 模型放哪里

节点会自动扫描 ComfyUI 模型目录下的 `LLM`（或 `llm`）文件夹，支持 `.gguf`：

```
ComfyUI/models/LLM/
├── Qwen-Image-2.1-PE-T2I.Q5_K_M.gguf     ← 文生图主模型
├── Qwen-Image-2.1-PE-I2I.Q5_K_M.gguf     ← 图生图主模型
└──（mmproj 视觉投影 gguf）                ← 接了图就必须有
```

- 只认 `qwen35` 架构的 GGUF；文件名里带 `qwen image` 或 `PE-` 的会优先显示。
- 文件名里带 `mmproj` 的会被识别成视觉模型，只出现在「视觉模型」下拉里。
- 新放进模型后**需要重启 ComfyUI** 才会出现在下拉列表里（列表只在启动时扫一次）。

